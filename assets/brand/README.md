# Belle's avatar and logo

These files are the canonical avatar and logo. The [NOTICE](../../NOTICE) says
how the License treats the Belle name and these marks.

## Avatar

The avatar is a desk bell on a walnut plinth. Use it where Belle takes part:
a chat message, a profile picture or an app icon. Its colours stay the same on
every background.

| File | Use |
| --- | --- |
| `avatar.svg` | Above 40 px, on a transparent background. The Slack app icon uses it. |
| `avatar-small.svg` | At 40 px and below. It has flat tones, larger eyes and no blur, so the face still reads. Do not use it below 24 px. |

## Logo

The logo is the bell's silhouette with its two eyes, in one colour. Set the
name Belle beside it in Fraunces.

| File | Use |
| --- | --- |
| `logo-light.svg` | On light backgrounds, in dark brass `#8a5a10`. Above 24 px. |
| `logo-dark.svg` | On dark backgrounds, in light brass `#d4a04a`. Above 24 px. |
| `logo-small-light.svg`, `logo-small-dark.svg` | At 24 px and below. It has larger eyes, a wider dome and a heavier button. Do not use it below 16 px. Use it as the favicon. |
